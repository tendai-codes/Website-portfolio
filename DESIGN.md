# Design notes

## Direction

The site uses a restrained scientific/editorial visual language: off-white/charcoal foundations, muted biological green, serif display typography, sans-serif interface text, generous whitespace and minimal motion.

The objective is to communicate work at the intersection of biology, computation, statistics and machine learning without turning the portfolio into either a generic developer dashboard or a dense academic website.

## Project media

Project evidence is presented as supporting material rather than oversized report screenshots.

- Homepage and archive project visuals remain compact, fixed-height editorial graphics.
- Case-study figures are arranged into responsive galleries.
- Two-column galleries are the default desktop treatment.
- Large galleries expand into three columns only when there is enough viewport width.
- Mobile uses one column.
- Figures are contained rather than cropped.
- Tables and wide outputs use shorter cards; tall scientific plots receive more vertical space.
- Responsive WebP derivatives are used in-page; originals are reserved for the lightbox.
- Captions remain attached to figures and a small gallery affordance tells users that full resolution is available.

## Content hierarchy

The site prioritises:

1. Clear professional positioning
2. Selected high-quality projects
3. Research/publication signal
4. Current MSc/technical direction
5. Writing
6. Contact

All 17 migrated projects remain accessible, but the homepage intentionally foregrounds only a small selected set.
